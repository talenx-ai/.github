# TalenX

TalenX builds a Workforce Intelligence Platform: a multi-tenant HR-tech SaaS layer that sits above a customer's existing HRMS, HIS, finance, attendance and ATS systems.
It reconciles workforce data into one governed model and benchmarks it against manning and cost norms.
It then surfaces prioritized, costed gaps as a tracked executive action plan.
Healthcare is our anchor vertical.
